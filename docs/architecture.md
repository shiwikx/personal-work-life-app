# 架构基线

## 环境决策

当前环境无法访问 npm 仓库。为不中断开发，第一版采用零第三方依赖方案，保持全部产品功能和验收标准不变：

- 本地服务：Node.js 内置 `node:http`。
- 数据库：Node.js 内置 `node:sqlite`。
- 页面：原生 HTML、CSS、JavaScript。
- 后台提醒与悬浮层：Node.js 后台进程 + Windows PowerShell WinForms/NotifyIcon。
- 测试：Node.js 内置 `node:test`，接口集成测试与 Chrome 无头页面测试。
- 导出：CSV 和完整 JSON/ZIP 数据包。
- 备份：SQLite 文件和设置文件的目录备份及 ZIP 完整包。

## 进程

- Node 本地服务：仅监听 127.0.0.1，提供 API 和静态页面。
- Node 后台进程：提醒调度、自启动、备份和桌面状态接口。
- PowerShell 桌面助手：系统托盘、悬浮窗口、提醒弹窗。
- 系统浏览器：运行主页面。

## 数据原则

- 业务数据不得只保存在浏览器存储中。
- 重复事项按日期范围计算，不预生成无限实例。
- 自动进度和手动进度分开存储。
- 备份、恢复和更换目录必须使用临时目录、校验和失败回滚。
- 应用使用单实例锁，避免重复提醒和并发写入。

## 本机约束

- 页面资源和图标全部本地提供。
- 运行时仅访问 localhost。
- 日期显示使用 Asia/Shanghai。
