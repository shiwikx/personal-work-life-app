# 用户使用说明

## 首次启动

1. 确认 D 盘存在并留有足够空间。
2. 双击便携包中的 `启动个人工作生活APP.cmd`。
3. 浏览器打开 `http://127.0.0.1:4123`。
4. 桌面右侧出现“今日未完成”悬浮窗口，系统托盘出现应用图标。

## 每日使用

- 首页查看今日未完成、已完成、下一条提醒和最近备份状态。
- 今日计划统一汇总各模块当天事项；模块中的事项会按日期自动出现。
- 在今日计划或首页勾选完成后，事项从今日视图消失，并保留在所属模块已完成记录中。
- 各模块支持自己的业务字段。开发计划包含项目、功能、缺陷、日志、计时和手动补录；秋招模块不包含公司、岗位、目标清单和投递渠道。
- 工作计划可以生成日报和周报，并保存手动补充。

## 计时

学习和开发计时状态保存在服务端数据库。刷新浏览器不会丢失计时；暂停、继续和结束操作会生成对应记录。

## 提醒与桌面助手

- 每条带有日期/时间的事项可设置提前提醒时间。
- 后台每 15 秒检查到期提醒，免打扰时段内暂停弹出。
- 到期提醒会通过 Windows 通知和桌面提醒窗口展示，可完成、稍后 10 分钟或打开详情。
- 悬浮窗口始终置顶、可拖动、可收起，并可从系统托盘恢复。
- 在设置中开启开机自启动后，Windows 登录时会运行启动脚本。

## 数据安全

- 所有写入使用本地 SQLite。
- 备份、恢复和目录切换均以事务式流程执行，恢复前自动创建安全备份。
- 如提示目录不可写，请先修复 D 盘权限或在设置中切换目录。

## 退出

使用 `停止个人工作生活APP.cmd` 停止后台服务。若开启自启动，停止操作不会改变自启动设置。
