# 已知问题

当前没有已知的高风险或核心数据丢失问题。

以下为环境限制或需要人工确认的事项：

1. 系统通知、声音和开机自启动受 Windows 通知权限、组策略和登录方式影响；应用会显示配置失败，但无法绕过系统策略。
2. 悬浮窗口由 PowerShell WinForms 实现，实际置顶和拖动手感需在目标电脑多显示器环境巡检。
3. 便携包包含 Node.js 运行时，但 Windows 安全软件可能首次拦截 PowerShell 脚本；需允许本机脚本执行。
4. 本版导出采用 UTF-8 BOM CSV 和 Excel 2003 XML（`.xls`），适合 Excel 打开；不是 XLSX 二进制格式。
