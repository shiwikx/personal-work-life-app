# 备份与恢复说明

## 备份内容

每次备份生成 ZIP 文件，包含：

- `manifest.json`：格式版本、时间、备份类型。
- `settings.json`：应用设置。
- `app.sqlite`：已完成 WAL checkpoint 的数据库快照。
- 完整数据包还会包含 `exports/` 中各模块 CSV。

## 手动备份

1. 打开“数据与设置”。
2. 点击“立即备份”。
3. 在备份历史中确认状态为“文件可用”。

## 恢复

1. 在备份历史中选择目标版本并点击“恢复”。
2. 确认后，系统先自动创建 `pre-restore` 安全备份。
3. 系统校验 ZIP 完整性、数据库版本和 SQLite 完整性，再原子替换当前数据库。
4. 校验或恢复失败时，当前数据库保持可用，并记录失败原因。

## 自动备份

- 开启后，每天首次启动执行一次；当天已备份则不重复。
- 保留数量可在设置中调整，超出数量时从最旧自动备份开始清理。
- 自动备份失败会写入最近备份状态，不会静默忽略。

## 完整数据包恢复验证

1. 在设置页下载完整数据包。
2. 将数据包复制到测试环境。
3. 新建空数据目录。
4. 在测试实例中恢复该 ZIP。
5. 核对各模块记录、设置和重复事项完成状态。

不要直接用唯一真实数据做第一次恢复试验。
